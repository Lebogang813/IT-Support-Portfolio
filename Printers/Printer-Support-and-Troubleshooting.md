# Printer Support and Troubleshooting – First-Line Support

## Overview

During my IT support experience, I handled basic printer support for users, including connecting them to the correct printer, adding printers to their devices, and resolving common printing problems. I also practised setting up a printer using both a cable connection and Wi-Fi.

## Support Tasks

- **Connect users to the correct printer**
  - Help users find and select the right printer for their location.

- **Add a printer to a user's device**
  - Add the printer on the user's computer so they can print.

- **Replace cartridges**
  - Replace empty printer cartridges.

- **Load paper correctly**
  - Reload and position paper properly to avoid paper problems.

- **Basic troubleshooting**
  - Restart the print spooler when print jobs were stuck or not printing.
  - Carry out basic checks to find and fix common printing problems.

## Practice: Printer Setup

I practised setting up a printer in two ways:

- Using a **cable (USB) connection**
- Using a **Wi-Fi connection**

- First-line technical support
