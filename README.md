A knowledge base of IT support guides covering Active Directory, device deployment, hardware, helpdesk support, networking, printers and asset management. Each guide documents how I handled real support tasks, step by step.

I built it because I enjoy understanding how enterprise IT systems work and documenting what I learn. It is a record of my skills and approach to solving problems, and it grows as I do.
