# Device Deployment and Commissioning

## Overview

During my IT support experience at The Documented Warehouse, I prepared and deployed laptops, desktops, thin clients, and other devices for users.

The process involved checking the device, preparing Windows, joining the machine to the company domain, applying required security settings, installing required software, recording the asset in DTA, and completing the user handover process.

## Initial Device Checks

Before deployment, I:

* Confirmed that the machine had the required **Windows Pro** edition.
* Obtained the asset tag.
* Checked DTA to make sure the asset did not already exist before tagging the machine.
* Physically attached the asset tag to the machine.
* Checked DTA when creating or updating the asset record.

## Machine Naming

* Checked DTA to confirm that the proposed machine name was not already being used for the relevant office.
* Used the office number displayed on the office door according to the company's naming standard.
* Assigned the machine name after confirming that it was not already in use.

## Windows and Domain Configuration

* Joined the machine to the company domain.
* Restarted the machine after joining the domain.
* Ran Windows Updates.
* Checked for missing drivers where required. Most machines already had the required drivers installed.
* Set the required regional settings.

## Administrator Account Configuration

* Added the two company-standard administrator accounts required during deployment.
* Unlocked the required administrator account where necessary.
* Set the administrator accounts to never expire according to the deployment requirements.

## Security Configuration

Security configuration depended on the type of device:

### Laptops

* Used ESET encryption or BitLocker depending on whether BitLocker was supported by the machine.

### Thin Clients

* Applied UWF (Unified Write Filter) as required.

## Required Software and DTA Auditing

Depending on the machine and deployment requirements, I installed and configured:

* AnyDesk
* ESET Antivirus
* LSService

LSService connects the machine to DTA and allows the machine to be audited.

After installation, I checked DTA to confirm that the machine was reporting/auditing correctly and that information such as the IP address and other machine details could be viewed.

## Asset Registration

After physically tagging the machine, I added or updated the machine in DTA.

Depending on whether a user had already been identified:

* Assigned the machine directly to the user, or
* Assigned it to the IT Storeroom until a user was identified.

When the machine was later issued, the DTA asset could be transferred from the IT Storeroom to the user.

## Final Deployment and Handover

Before handing over the machine, I followed the required deployment process and confirmed that the machine was ready for use.

### Users at Our Location

* Completed the machine acceptance form.
* Provided the form to the user for signature.
* Handed the configured machine to the user.
* Received the signed acceptance form.

### Branch Users

* Prepared the machine for deployment.
* Sent the machine to the branch using a courier or company driver.
* Sent the acceptance form to the branch/user by email.
* The user signed the form and returned the completed form by email.
